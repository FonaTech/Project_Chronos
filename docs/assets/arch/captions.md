## 块内部结构

Supported attention and MLP configurations in Chronos blocks. The full pre-normalization residual path combines attention with either a dense feed-forward network (FFN) or a mixture of experts (MoE). Multi-head latent attention (MLA) uses global causal context and latent key–value (KV) storage. Sliding-window attention (SWA) limits local context to W. With the default SiLU activation, dense FFNs use SwiGLU with configurable width d_ff. Under the same activation, routed and shared experts use SwiGLU, with configurable expert width d_e. The router selects k of E experts; their weighted outputs are added to the mean output of S shared experts when configured; omit that branch at S=0. Solid lines carry hidden states; orange dashes carry gates. The cards are alternatives, not a fixed execution order. In first_only recurrence, later iterations bypass the attention sublayer. RMSNorm, root mean square normalization; SwiGLU, swish gated linear unit; MLP, multilayer perceptron.

Chronos 块支持的注意力与 MLP 配置。完整的预归一化残差路径将注意力与稠密前馈网络（FFN）或混合专家（MoE）组合。多头潜在注意力（MLA）使用全局因果上下文和潜在键值（KV）存储。滑动窗口注意力（SWA）将局部上下文限制为 W。默认 SiLU 激活下，稠密 FFN 采用 SwiGLU，宽度 d_ff 可配置。相同激活设置下，路由与共享专家也采用 SwiGLU，专家宽度 d_e 可配置。Router 从 E 个专家中选择 k 个，将其加权输出与 S 个共享专家的输出均值相加；S=0 时省略共享分支。实线传递隐藏状态，橙色虚线传递门控。四张卡片是替代配置，不是固定执行顺序。在 first_only 循环模式下，后续迭代跳过注意力子层。RMSNorm，均方根归一化；SwiGLU，swish 门控线性单元；MLP，多层感知机。
